01 / AI & AUTOMATION

AI News Scraper

A pipeline that turns multiple news sources into a structured editorial workflow.

The challenge

Collect stories from multiple sources, avoid repeatedly processing near-identical reporting, and provide a readable frontend for the resulting content.

What I built

  • Python and Playwright collection with Sentence-BERT embedding-based deduplication.
  • Fact extraction and local Ollama-based article generation.
  • A versioned Django JSON API with OpenAPI/Swagger documentation.
  • A React newspaper frontend with category sections, a trending feed, view analytics, regression tests, and GitHub Actions CI.

Project description supplied in my CV. Source code is not linked publicly. The portfolio illustration is not a live application; generated content still requires editorial review.

02 / APPLIED AI

Folio — RAG Document Chat

Ask questions of PDF documents and follow an answer back to its source.

The approach

Page-level chunking with PyMuPDF, ChromaDB MMR retrieval, and LangChain orchestration. Citations identify the file, page, and verbatim source quote.

What I built

  • A FastAPI and Jinja2 interface with SSE response streaming.
  • A document upload library and source-scoped chat memory.
  • OpenAI/Anthropic provider integration and pytest coverage.
